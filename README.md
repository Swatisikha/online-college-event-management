# Online College Event Management System

## Project Overview
The Online College Event Management System is a web-based application developed using Python, Django, HTML, CSS, and MySQL. It helps students view college events and register for events online.

## Features
- Student sign up and login
- View available college events
- Register for college events
- Prevent duplicate event registrations
- View personal registrations
- Student dashboard
- Django Admin panel for managing events and viewing registrations
- Login protection for restricted pages

## Technologies Used
- Python
- Django
- HTML
- CSS
- MySQL
- Git and GitHub

## Requirements
Install Python and MySQL before setting up the project.

## Installation
1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Create and activate a virtual environment.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Create a MySQL database named `college_event_db`.
6. Configure your database credentials in Django settings.
7. Apply migrations:

   `python manage.py migrate`

8. Create an administrator account:

   `python manage.py createsuperuser`

9. Start the development server:

   `python manage.py runserver`

10. Open `http://127.0.0.1:8000/` in your browser.
